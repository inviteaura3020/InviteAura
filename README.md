# InviteAura wedding website starter

Run locally: install Node.js LTS, open a terminal in this folder, run `npm install`, then `npm run dev`.

Demo content uses Aarav & Kiara, 14 Feb 2027 and a sample Jaipur venue. Replace before customer delivery. RSVP currently only shows a demo confirmation; it does not save or email responses. Music control is a visual placeholder, not an audio player. Replace stock photos with properly licensed assets and connect a real RSVP backend and confirmed venue/map URL before selling.
